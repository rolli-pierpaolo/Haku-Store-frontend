# Haku Store - Frontend

Frontend Angular di un e-commerce full stack, collegato a una REST API Spring Boot.

## Funzionalita

- Registrazione e login con autenticazione JWT
- Catalogo prodotti, categorie e varianti
- Dettaglio prodotto, recensioni e carrello
- Checkout, indirizzi e storico ordini
- Gestione profilo utente
- Area amministrativa per prodotti, categorie, ordini e coupon

## Tecnologie

- Angular
- TypeScript
- Angular Material
- HTML e CSS
- REST API
- JWT

## Avvio

Installa le dipendenze e avvia il server di sviluppo:

```bash
npm install
npm start
```

L'applicazione sara disponibile su `http://localhost:4200`.

## Backend

La REST API e disponibile nella repository [Haku Store Backend](https://github.com/rolli-pierpaolo/Haku-Store-backend).
